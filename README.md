How to Use:
Open the application in your browser.
Paste a valid URL into the input field.
Click the Shorten URL button.
Copy the generated short URL.
Open the short URL to be redirected to the original website.

Note: When running locally, generated links use localhost and will only work on your computer. To share links with others, deploy the application to a hosting service such as Render or Railway.
